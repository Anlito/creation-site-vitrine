Outil de création de site vitrine · Projet de technologie « Concept Store 4.0 » · 4e · Version {{VERSION}} du {{DATE}}

En bref : Vitrine tient dans un seul fichier (index.html). Rien à installer, aucun compte, aucune connexion internet nécessaire, aucune donnée envoyée sur internet. Il suffit de copier le dossier Vitrine sur le serveur de la classe, puis d'ouvrir index.html avec Chrome ou Edge.

2. Installer sur le serveur d'une classe

À faire une fois par classe (par exemple pour 4A, 4B…). Arborescence conseillée, dans le dossier commun de la classe :

4X
└─ Commun
   └─ TECHNOLOGIE
      └─ CONCEPT STORE
         ├─ Vitrine            ← l'outil : copier ici le dossier « Vitrine » du livrable
         │  └─ index.html
         ├─ Inès               ← un dossier par élève (ou par groupe),
         ├─ Hugo                  où chacun enregistre son fichier .vitrine
         └─ …
  1. Copier le dossier Vitrine du livrable dans 4X › Commun › TECHNOLOGIE › CONCEPT STORE.
  2. Créer (ou vérifier) un dossier par élève, à son prénom, au même endroit. Les élèves doivent pouvoir écrire dans leur dossier.
  3. Conseillé : mettre le dossier Vitrine en lecture seule pour les élèves, pour éviter qu'il soit supprimé ou modifié par erreur.
  4. Ouvrir Vitrine/index.html sur un poste élève pour vérifier (voir la partie 5).
Le chemin conseillé est rappelé aux élèves dans l'outil (« Range ton projet dans : 4B › Commun › TECHNOLOGIE › CONCEPT STORE › Prénom-Prénom (ton équipe) »). Le nom de la classe vient de ce que l'élève saisit au début (« 4e B » devient « 4B »).

Variante : serveur web (intranet, ENT)

Vitrine fonctionne aussi déposé sur un serveur web. Attention : pour que les élèves puissent choisir leur dossier d'enregistrement, l'adresse doit commencer par https://. En http:// simple, le navigateur bloque cette fonction et les projets sont enregistrés dans le dossier Téléchargements (les élèves doivent alors les déplacer eux-mêmes).

3. Donner l'accès aux élèves

  • Le plus simple : les élèves ouvrent CONCEPT STORE › Vitrine › index.html par double-clic.
  • Raccourci sur le bureau : clic droit sur index.html › Afficher d'autres options › Envoyer vers › Bureau (créer un raccourci), puis renommer le raccourci « Vitrine ». Ce raccourci peut être déployé par le service informatique (GPO).
  • Favori : une fois index.html ouvert dans Chrome ou Edge, ajouter la page aux favoris (Ctrl + D).

5. Vérifier l'installation (5 minutes, sur un poste élève)

Ouvrir Vitrine/index.html : l'accueil « Crée le site de ton concept store » s'affiche.

« Créer un nouveau projet » : saisir un nom, une classe et des prénoms de test.

Cliquer sur « Enregistrer » : la fenêtre « Enregistrer sous » s'ouvre. Choisir un dossier élève sur le serveur et enregistrer.
→ Si un message indique que le fichier est parti dans Téléchargements, voir « Dépannage ».

Recharger la page (F5), cliquer sur « Ouvrir mon projet » et rouvrir le fichier : le projet revient.

Onglet « Vérifier et exporter » › « Exporter mon site » : un fichier .zip arrive dans Téléchargements ; l'ouvrir et double-cliquer sur index.html.

Lien « Espace enseignant » (en bas à droite de l'accueil) : le mot de passe est demandé.

Supprimer ensuite le fichier de test.

6. Espace enseignant

  • Accès : lien « Espace enseignant » en bas à droite de l'accueil. Mot de passe : 2534. Il est demandé une fois par séance ; le bouton « Verrouiller » le redemande aussitôt.
  • « Ouvrir un projet » : choisir le fichier .vitrine d'un élève. Le site s'affiche en lecture seule, avec le contrôle automatique (9 points) et la grille sur 20.
  • Les évaluations sont gardées dans le navigateur du poste où elles sont faites : évaluer toute la classe sur le même poste (de préférence le poste enseignant), puis « Exporter en CSV » (s'ouvre directement dans Excel).
À savoir : l'outil fonctionne sans serveur, donc ce mot de passe empêche surtout d'entrer par curiosité ; ce n'est pas une protection forte. Éviter d'évaluer sur un poste élève.

7. Mettre à jour Vitrine

  1. Remplacer Vitrine/index.html par la nouvelle version, dans chaque classe.
  2. Demander aux élèves de recharger la page (F5) si l'outil était déjà ouvert.

Les projets .vitrine déjà enregistrés restent compatibles : ils s'ouvrent dans la nouvelle version.

8. Dépannage

SituationSolution
« Enregistrer » ne propose pas de choisir le dossier ; le fichier part dans Téléchargements.Utiliser Chrome ou Edge. Si c'est déjà le cas, le navigateur n'a peut-être pas le droit d'écrire sur le lecteur réseau : l'élève déplace alors son fichier de Téléchargements vers son dossier (l'outil le lui indique). À signaler au service informatique.
« Ce fichier ne peut pas être ouvert. »L'élève a choisi un autre fichier : il faut celui qui se termine par .vitrine.
Un élève a fermé l'onglet sans enregistrer.Le travail depuis le dernier enregistrement est perdu. Le navigateur demande une confirmation avant de fermer : rappeler d'enregistrer souvent.
Une image est refusée ou très lente.Les images de plus de 1 Mo sont réduites automatiquement ; préférer des photos JPG ou PNG.
L'affichage est coupé ou trop serré.Agrandir la fenêtre du navigateur, ou revenir au zoom 100 % (Ctrl + 0).
Les élèves ne savent pas par où commencer.Bouton « Aide » en haut à droite : visite guidée de chaque partie et questions fréquentes. Imprimer la fiche élève.

9. Données et confidentialité

  • Aucun compte, aucune adresse e-mail, aucun serveur : rien n'est envoyé sur internet.
  • Le travail de l'élève est dans son fichier .vitrine, sur le serveur de la classe (prénoms du groupe, textes et images du projet).
  • Les polices et les icônes sont incluses dans l'outil ; les polices importées par les élèves (Google Fonts) sont téléchargées par eux puis rangées dans leur projet.
  • Le formulaire de contact des sites créés est un exemple : il n'envoie aucun message.
